# ♻️ O Perigo Escondido no Lixo

## 📖 Sobre o Projeto

Este projeto é um site estático desenvolvido como trabalho acadêmico. O objetivo é informar a população sobre os riscos de descartar objetos cortantes (como vidro quebrado, agulhas e latas) no lixo comum sem a devida proteção.

O conteúdo aborda:
* **Os Riscos:** Como pequenos descuidos causam acidentes graves nos coletores.
* **Tipos de Materiais:** Vidros, agulhas, espetos e latas.
* **Guia Educativo:** Passo a passo de como embalar e descartar corretamente.

## 🎯 Funcionalidades e Seções

O site foi estruturado seguindo o wireframe proposto, contendo:

1.  **Hero Section:** Chamada de impacto ("O Perigo Escondido no Lixo").
2.  **Seção de Conscientização:** Explicação sobre "Armadilhas Invisíveis" e dados sobre acidentes.
3.  **Tutorial de Descarte (4 Passos):**
    * 📦 Como embalar vidros e louças.
    * bottle Como usar garrafas PET para agulhas e pontiagudos.
    * 🏷️ A importância da identificação (etiquetas).
    * 🥫 Cuidados com tampas de latas serrilhadas.
4.  **Rodapé:** Informações de contato e créditos.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, layout responsivo e design visual.
